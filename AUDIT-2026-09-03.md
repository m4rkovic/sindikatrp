# SindikatRP — Audit i roadmap (2026-09-03)

Pregled repo-a `m4rkovic/sindikatrp` (Next.js 16 / React 19 / TypeScript / SQLite). Opšta ocena: kodna baza je **znatno iznad proseka** — čist App Router, jasne server/client granice, parametrizovan SQL svuda, scrypt hash, hash-ovane sesije, CSRF na svim admin akcijama, sharp re-enkodovanje upload-a, strogo validiran upload route, dobar responsive i `prefers-reduced-motion`. Nalazi ispod su ciljani, ne generički.

## Nalazi

### CRITICAL

Nema nalaza koji ruše sajt ili daju direktan pristup. Najbliži tome je prvi HIGH nalaz.

### HIGH

1. **`data/sindikat.db` je commitovan u javni repo** (uključujući `-shm`/`-wal`).
   - *Šta:* Baza sadrži `users.password_hash` (scrypt) i istoriju sesija/audita. Repo nema `.gitignore` uopšte.
   - *Zašto:* Hash u javnom repou je meta za offline napad; scrypt kupuje vreme, ali ne poništava rizik. Audit log otkriva i IP adrese.
   - *Rešenje:* ✅ Dodat `.gitignore` (baza, `secret.key`, `data/uploads/`, `node_modules`, `.next`, `.env*`). U README dodata napomena: promeniti admin lozinku i očistiti git istoriju ako repo ostaje javan. Baza je ostavljena netaknuta u projektu (podaci nisu dirani).

2. **Brute-force zaštita je bila isključena bez reverse proxy-ja** — `lib/auth.ts`.
   - *Šta:* `clientIp()` čita samo `cf-connecting-ip`/`x-real-ip`. Na golom Node deploy-u oba su prazna → `loginBlocked(null)` je vraćao `false` bezuslovno. Uz to, `x-real-ip` je lako lažirati kada ispred ne stoji proxy, pa je rotiranjem header-a limit mogao da se zaobiđe i kad IP postoji.
   - *Rešenje:* ✅ `null` IP sada pada u zajedničku `unknown` kofu (limit i dalje važi), a dodat je i globalni plafon pokušaja u prozoru (60/15 min) nezavisan od IP-ja, pa lažirane adrese ne pomažu.

### MEDIUM

3. **Nema `not-found` i `error` stranica** — kada nešto pukne, korisnik je dobijao sirovi Next fallback koji vizuelno nema veze sa sajtom.
   - *Rešenje:* ✅ Dodati `app/not-found.tsx` i `app/error.tsx` u design language-u sajta (`.fault` blok u `globals.css`).

4. **`force-dynamic` na homepage-u i `/donacije`** — svaki zahtev je išao kroz SSR + SQLite, iako se katalog menja samo kroz admin, a admin akcije već zovu `revalidatePath('/')` i `revalidatePath('/donacije')`.
   - *Rešenje:* ✅ Zamenjeno sa `revalidate = 300` (ISR). Stranice su sada statičke između izmena → osetno brži TTFB/LCP, a promene iz panela su i dalje trenutna zahvaljujući `revalidatePath`. API rute (`/api/status`, `/api/paketi`) ostaju dinamičke.

5. **Fokus indikatori i skip-link** — public sajt se oslanjao na default browser outline, skip-link nije postojao.
   - *Rešenje:* ✅ Globalni `:focus-visible` stil (accent outline) + „Preskoči na sadržaj" skip-link u `app/(site)/layout.tsx`, `<main id="sadrzaj">`.

### LOW

6. **Duplirane konfiguracione vrednosti** — sezona („SEZONA 04 · NEW BEGINNING", „S04", „04 · New Beginning") i broj slotova (48) bili hardkodovani na 5 mesta (hero eyebrow, hero badge, hero-stat, `serverFacts`, prose na homepage-u), iako `site.season` i `server.maxPlayers` postoje u `lib/data/site.ts`.
   - *Rešenje:* ✅ Dodati `seasonCode`/`seasonShort` u `site.ts`; sva mesta sada čitaju iz konfiguracije. Promena sezone je sada izmena jednog objekta.

7. **Hero je pre prvog fetch-a tvrdio „SERVER ONLINE"** — početno stanje je bilo hardkodovano `online: true, maxPlayers: 48`. Sada čita `server.online`/`server.maxPlayers` iz konfiguracije (i dalje se u sekundi zameni live podatkom).

8. **Admin ikonice bez `aria-label`** — dugmad za redosled/vidljivost/izmenu imala su samo `title`. ✅ Dodati `aria-label`-i sa imenom paketa.

9. **SEO metadata** — nedostajali `alternates.canonical` i `twitter.card`. ✅ Dodato u root layout.

10. **DX** — nije postojao `.env.example`; `npm install` na Windows-u bez Visual Studio-a pada na `better-sqlite3` (npm pokreće `node-gyp` uprkos isporučenom prebuild binarnom fajlu). ✅ Dodat `.env.example` i README napomena (`npm install --ignore-scripts` radi, prebuild se koristi u runtime-u).

### Zabeleženo, namerno NIJE dirano

- **CSP header** — uvođenje Content-Security-Policy u Next zahteva nonce pipeline; rizik od tihog lomljenja stranica je veći od dobiti za ovaj sajt. Preporuka za kasnije, uz testiranje.
- **HSTS** — zavisi od TLS terminacije na hostu; ne treba ga slati naslepo iz aplikacije.
- **`favicon.png` (196 KB)** — radi, ali je težak za favicon; opciono generisati 256px verziju.
- **Testovi** — ne postoje. Realan minimalni setup: Vitest za `lib/` (validation, packages, password, status normalizaciju) + Playwright smoke (homepage, pravila, admin login + CRUD paketa). Nije dodavano sada da ZIP ne bi menjao stack bez dogovora.
- **Rate limiting javnih API ruta** — `/api/status` je keširan u memoriji (20s), pa je jeftin; nije kritično.
- **`package-lock.json`** — instalacija je verifikovana sa `--ignore-scripts`; lock fajl nije menjan.
